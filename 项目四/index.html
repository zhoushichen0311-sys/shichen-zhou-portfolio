城乡过渡空间评估引擎

一个把「城市更新」变成可计算流程的空间评估工具：输入场地现状，系统按整合度、私密性、建筑密度打分，输出分阶段的空间演化策略。

试用产品 Demo → Input → Process → Output
背景 / CONTEXT

城市化正在吞噬乡土 —— 但没人能「量化」这个过程。

产品 Demo 以石家庄地铁 4 号线为例，石家庄地铁 4 号线不服务城区，而是伸向乡村，成为城市扩张的工具。原住民被迫改变居住、出行与谋生方式，城乡之间出现一段脆弱的「过渡带」。规划者却缺少工具去评估：这段过渡空间质量如何？会怎样演化？这正是这个产品要解决的问题。

过渡户型 / HOUSING TYPES

从院落到公寓：两代过渡户型设计

评估引擎负责判断「哪里适合过渡」，而这两代过渡户型是我设计的空间单元，回答「过渡的居住空间长什么样」。每个户型都经过室内动线与公共 / 私密路径分析，在保留乡土生活方式的同时逐步适应城市居住密度。

两层布局，保留乡村住宅多代同堂的居住结构；流线简单，具备一定私密性 —— 从院落走向公寓的第一步。
